# プライバシーポリシー

本リポジトリは、kumayy-dev が Microsoft Store で公開する Windows アプリのプライバシーポリシーを GitHub Pages で公開するものです。

## 公開ページ

[プライバシーポリシー](https://kumayy-dev.github.io/privacy-policy/)

## 対象アプリ

- FileDateStamper
- MSStoreIconGenerator

## MSStoreIconGenerator のデータ取り扱い

- 個人情報は収集しません。
- 利用者が読み込ませた画像を端末内で処理し、生成した画像ファイルは元画像と同じフォルダーに保存します。
- 画像データを外部へ送信する機能や、ネットワーク通信機能はありません。

詳細は上記のプライバシーポリシーをご確認ください。
