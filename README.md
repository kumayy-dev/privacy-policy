# プライバシーポリシー

本リポジトリは、kumayy-dev が Microsoft Store で公開する Windows アプリのプライバシーポリシーを GitHub Pages で公開するものです。

## 公開ページ

[プライバシーポリシー](https://kumayy-dev.github.io/privacy-policy/)

## 対象アプリ

- FileDateStamper
- MSStoreIconGenerator
- NoPastePaste
- PanoLa
- BoxDriveFix
- DropPhotoResizer

## MSStoreIconGenerator のデータ取り扱い

- 個人情報は収集しません。
- 利用者が読み込ませた画像を端末内で処理し、生成した画像ファイルは元画像と同じフォルダーに保存します。
- 画像データを外部へ送信する機能や、ネットワーク通信機能はありません。

## NoPastePaste のデータ取り扱い

- 個人情報は収集しません。
- 入力欄のテキストは、入力先へキー入力として送信するためにのみ使用し、外部へ送信しません。
- クリップボードの読み取り・書き込みは行いません。
- テーマ設定を端末内のユーザー別設定領域に保存します。
- アプリ自体によるネットワーク通信はありません（ヘルプのリンクを開く場合のみ既定ブラウザーが通信します）。

## PanoLa のデータ取り扱い

- 個人情報は収集しません。
- 利用者が登録したアプリやファイルの起動情報、タイルの配置・整理情報を端末内のユーザー別領域に保存し、当方へ送信しません。
- スタートメニューに登録されたアプリを追加候補として検索します。実行ファイル、ショートカット、インターネットショートカットは利用者が選択して登録します。
- 登録したインターネットショートカットを起動すると、リンク先との通信が発生することがあります。

## BoxDriveFix のデータ取り扱い

- 個人を特定できる情報の収集を目的とする機能はありません。
- Box Drive の雲アイコン表示設定（レジストリの EnableCloudFiles）、未同期ファイルの件数およびログの更新状況を端末内で確認し、設定の有効化や Box Drive の再起動に使用します。ファイルの内容を収集する機能はありません。
- 確認した設定・状態情報を当方へ送信しません。BoxDriveFix の設定確認・修復機能にネットワーク通信は含まれません。
- レジストリ設定の有効化には利用者が UAC で承認する管理者権限が必要で、アプリから元に戻すことはできません。Box Drive 自身の同期等による通信は本アプリの通信ではありません。

## DropPhotoResizer のデータ取り扱い

- 個人情報は収集しません。
- 利用者が追加した画像または指定フォルダー直下の画像を端末内で縮小・変換し、元画像と同じ場所の `DropPhotoResizer_Output` フォルダーに保存します。元画像は変更しません。
- 画像のメタデータは設定に従って削除または出力画像に保持します。対象一覧と処理履歴は保存しません。
- テーマ、表示言語および設定画面で保存した起動時設定は端末内に保存します。
- 画像、メタデータ、設定情報を外部へ送信する機能や、アプリ自体のネットワーク通信機能はありません。

詳細は上記のプライバシーポリシーをご確認ください。
